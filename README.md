## Internship
Future Interns – Data Science & Analytics

## Task 3
Marketing Funnel & Conversion Performance Analysis

## Project Overview
This project analyzes marketing campaign data to understand customer conversion performance, identify unsuccessful campaign outcomes, and evaluate the factors influencing subscription decisions.

## Objective
- Analyze marketing campaign performance.
- Calculate conversion and failure rates.
- Identify successful and unsuccessful subscription outcomes.
- Compare performance across different customer segments.
- Provide recommendations to improve conversions.

## Tools Used
- Microsoft Power BI
- Power Query
- DAX

## Dashboard Features
- Total Contacts
- Successful Subscriptions
- Conversion Rate
- Unsuccessful Contacts
- Failure Rate
- Contact Channel Analysis
- Job Category Analysis
- Monthly Subscription Analysis
- Education Analysis
- Subscription Outcome Distribution
- Interactive Filters

## Key Insights
- The dashboard highlights the overall campaign conversion performance.
- It compares successful and unsuccessful subscription outcomes.
- It helps identify differences across contact channels and customer segments.
- It provides an overview of monthly subscription trends.

## Recommendations
- Improve campaign targeting.
- Focus on effective contact channels.
- Identify customer segments with better conversion performance.
- Improve follow-up strategies.
- Optimize campaign timing.
